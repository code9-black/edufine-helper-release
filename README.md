# 에듀파인 공문 도우미 — PC 도우미 설치 파일

크롬 확장(웹스토어): https://chromewebstore.google.com/detail/bajlacegkbnbpojbjekgoekpkpcopcdk (심사 통과 후 열림)

K-에듀파인 결재 공문을 엑셀에 기록하고 일괄과제결재를 도와주는 크롬 확장 **"에듀파인 공문 도우미"**의 PC 도우미입니다.

## 받기
**[EdufineHelper.exe 받기](https://github.com/code9-black/edufine-helper-release/releases/latest/download/EdufineHelper.exe)**

1. 받은 `EdufineHelper.exe` 더블클릭
2. 파란 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
3. "설치를 마쳤습니다" 창이 뜨면 끝 (받은 파일은 지워도 됩니다)

지우기: `%LOCALAPPDATA%\EdufineHelper\EdufineHelper.exe --uninstall`

이 저장소에는 설치 파일만 올라옵니다(자동 빌드).
